# 2026-09-14 5E 对话系统重构（talk.tscn）

- **完全替代 dialogue_box.gd**（已删除文件+.uid）：系统提示（获得物品）、事件对话（action_dialogue）、人物对话（_do_talk）全部走 talk.tscn。
- **talk.gd 设计**：`open(lines, portraits, bg_texture)`，lines 每项 `{"speaker","text","side"}`（side ∈ left1/left2/right1/right2，系统提示省略 side）；portraits {说话人: Texture2D}；右侧槽强制 flip_h（用户确认"以文档为准"：素资默认面向右）；BG 背景CG null=关卡内不显示。
- **逐字显示**：`visible_characters` Tween（CHAR_DELAY 0.04s/字）；yes 打字中=kill tween+visible_characters=-1 立即显完整句，打字完=下一句；no=跳过全部。
- **Dialogue 动态框体**：`font.get_multiline_string_size(text, LEFT, 204, 12)` 测量 + 手动补 line_spacing + MarginContainer 边距(16,14)，clamp 到场景 min 91×48 / max 224×64，`position.y = 81 - size.y` 下边界恒 81，左边缘固定 8。不用 Label.get_minimum_size（autowrap 下最小尺寸不可靠）。
- **箭头浮动动画**：Tween offset_top/offset_bottom（锚点偏移），不捕获 position——避免 Dialogue 改尺寸后漂移。
- **battle_manager**：dialogue_box→talk_scene（set_talk_scene）；`open_dialogue(speaker, lines)` 保留为系统提示包装（转 dict 格式走 play_dialogue，action_dialogue.gd 零改动）；`play_dialogue(lines, portraits, bg)` 正式入口；`set_talk_provider(cb)` 关卡注入 `func(unit, target) -> {"lines","portraits"}`，_do_talk 播完清空双方 talk 字段（FE 惯例防重复）。
- **level_0**：TALK_TE_ISAR 测试对话四句（忒 right1 / 伊萨尔 left1），TE_CARD/ISAR_CARD 肖像，_get_talk_dialogue 按单位名对匹配。
- 注意：对话播过一次 talk 字段被清空，反复测试需恢复 te.tscn/isar.tscn 的 talk 值。
