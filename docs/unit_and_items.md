# 单位、物品与角色成长系统

---

## 一、单位（Unit）数据模型

每个在战场上可行动的实体（玩家、友军、敌人）均为一个 `Unit` 实例，核心数据结构包括：

1. **八项能力与体格**：
   - 基础值：`str, mag, skl, spd, luk, def_h, res, move, con, hp, max_hp`。
   - 综合有效值查询统一走 `get_effective_*` 接口（自动计算装备额外加成及光环加成，如 `get_effective_skl()`、`get_effective_def(all_units)`）。
2. **职业数据 (`ClassData`)**：
   - 承载职业名、职业卡、能力上限（`cap_*`）、职业成长率、移动消耗表与骑乘类型（步行 / 骑乘·男 / 骑乘·女）。
3. **救援力 (Aid)**：
   - 步行：$\text{Aid} = \text{体格} - 1$
   - 骑乘·男：$\text{Aid} = 25 - \text{体格}$
   - 骑乘·女：$\text{Aid} = 20 - \text{体格}$

## 二、物品与背包生命周期（关键架构约定）

为防止多人开发/AI维护过程中出现“耐久状态不同步”、“已坏武器仍装备”等典型缺陷，严格规定以下生命周期不变量：

```text
[外部系统: 关卡掉落/开箱/交换/运输队/换装]
                 │
                 ▼ 唯一调用入口（严禁直接操作 inventory 数组）
┌────────────────────────────────────────────────────────┐
│ Unit 物品生命周期统一接口：                             │
│ • add_item(item: Item) -> bool                         │
│ • remove_item(item: Item) -> bool                      │
│ • remove_item_at(index: int) -> Item                   │
│ • equip_item(weapon: Weapon) -> bool                   │
│ • consume_weapon_durability(amount: int) -> bool       │
│ • break_current_weapon() -> void                       │
└────────────────────────────────────────────────────────┘
```

### 核心不变量原则：
1. **背包实例唯一性**：`current_weapon` 必须指向 `inventory` 数组内的某个具体实例，严禁脱离背包单独实例化武器。
2. **模板隔离**：所有从 `.tres` 读取的物品，放入背包前必须执行 `duplicate()`，避免多个单位共享同一模板造成耐久互相污染。
3. **损坏自卸装**：武器耐久降至 0 时，自动触发 `break_current_weapon()`，同时卸下装备并从背包中销毁。
4. **背包上限**：常量 `Unit.BAG_LIMIT = 5`。

## 三、武器等级与熟练度（Weapon Rank）

武器熟练度定义在 `scripts/weapon.gd` 中，阈值遵循 FE8 原版标准：

| 等级 | 所需武器经验 (WEXP) | 说明 |
| :---: | :---: | :--- |
| **E** | 1 | 基础入门武器（铁系武器） |
| **D** | 31 | 进阶武器（钢系武器、投枪） |
| **C** | 71 | 特殊效果武器（破甲剑、必杀剑、勇者武器） |
| **B** | 121 | 高级武器（银系武器） |
| **A** | 181 | 顶级武器 |
| **S** | 251 | 专属神器（如断弦，附带特技与高额属性增益） |

- **数据归属**：`rank_*` 归属于 `Unit`，表示该单位各武器类型的可用性与**等级上限**；`weapon_xp` 字典存储各类型累计经验。
- **装备判定**：`can_equip()` 校验单位当前的有效等级（`get_weapon_ex`）是否满足武器的 `required_rank`。

## 四、支援系统（Support System）

采用 FE8 属性加成与定制的章节出战积累机制：
1. **积累规则**：我方胜利结算时，双方均登场出战的支援对自动增加 1 点支援值（上限达 A 级门槛）。
2. **升级触发**：达到门槛后，行动菜单在相邻时动态显示“支援”选项，播放对话后正式升阶。
3. **加成结算**：曼哈顿距离 $\le 3$ 格生效，根据双方属性（炎/暗/理/雷/冰/光/风）贡献度之和乘以支援等级倍率（C:1x, B:2x, A:3x）。
