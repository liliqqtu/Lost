# 审查问题修复记录与存档约定

本轮按审查顺序处理存档、治疗、战斗合法性、终局/救援、会话隔离、输入收尾和测试入口。原审查报告保留为历史基线，修复状态以本文及 `问题.md` 为准。

## 已实现

1. **章中存档和跨章成长**：新版 JSON 记录全部单位、登记/隐藏状态、属性、经验、装备与耐久、位置、行动状态、救援关系、事件完成、交互物、Boss 台词记录、仓库、支援和菜单上下文。读取章节后覆盖场景默认状态；章中恢复跳过开场与已执行事件。跨章传递队伍，下一章回满 HP 并恢复行动资格；已记录阵亡的角色不重新出场。
2. **章节路径及通关状态**：章节存档保存下一章路径与标题；最后一章写入 `cleared` 并回到标题。旧自动存档缺失路径时按章节 ID 修复。已通关槽位在操作菜单显示“已通关”。
3. **治疗与经验**：动画只显示治疗结果，法杖确认统一提交真实 HP。辅助动作和普通战斗共用经验升级入口，无动画时同样升级。修复治疗预览的类型错误，未修改升级面板演出动画。
4. **耐久与攻击规则**：序列按耐久限制打击次数，并绑定本次武器；每击执行前再次验证合法性。蓝军和绿军不敌对，法杖不攻击、不反击、不计入攻击威胁区，不可装备的武器也不产生范围。背包候选武器按自身技能计算射程。
5. **AI 武器选择**：用临时单位计算候选武器的伤害和命中，计划同时返回站位、目标和武器；执行前换装并复核射程，不修改真实单位来做预览。
6. **终局和救援**：败北接入“重试/主菜单”；重试加载当前槽位有效存档，无有效存档时重新开始当前地图。携带者死亡先解除双向引用，被携带者在死亡格落地并标记已行动。
7. **会话隔离和时长**：新游戏/读档替换仓库、支援、阵亡名单和待恢复状态；加载后再覆盖关卡种子，空仓库不会被默认物品填回。时长按会话增量累计，不重复加进程总时长。
8. **输入及背包绑定**：保存/取消返回标题确认后恢复原菜单；隐藏运输队不再造成“保存/主菜单”选项错位。再移动执行期间忽略重复确认和取消。初始装备在背包复制后重绑到对应实例，恢复背包通过 Unit 接口完成。
9. **补充修正**：武器经验默认从 E 阈值开始，角色场景显式保留原初始熟练度；移动与威胁范围使用有效移动力；修复职业资源的 `cap_def_h` 字段。
10. **模块和测试**：移动/寻路/落点逻辑拆到 `battle_movement.gd`，保留门面旧接口。测试统一在 autoload 之后运行，修复失效引用、类型错误、夹具配置和过期断言；日志错误也导致测试命令失败。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `save_manager.gd` | 槽位 I/O、临时文件替换与备份、会话初始化、时长、恢复入口 |
| `campaign_snapshot.gd` | 章节表、战局捕获/恢复、按角色 ID 传递跨章队伍 |
| `save_codec.gd` | JSON 值与物品实例转换、单位字段及装备索引恢复 |
| `battle_movement.gd` | 选择/取消、移动路径和动画、落点更新、路径预览 |
| `battle_calculator.gd` | 阵营关系、攻击资格、纯数值和打击序列 |
| `battle_combat.gd` | 打击执行、耐久提交、通用经验升级 |

## 存档 v2

- `save_kind` 区分 `new_game`、`chapter_start`、`battle`、`cleared`。`chapter_scene` 和 `chapter_id` 指向加载目标，不从 UI 展示文字推断路径。
- 可操作的玩家回合地图/行动菜单才可保存；不保存正在播放的战斗、对话、事件或移动协程。
- 角色用 `unit_id`（当前 `te`、`isar`、`reyn`、`vera`）稳定识别。地图普通单位按 Units 下节点路径识别；运行时增援同时保存来源场景。救援引用先恢复单位，再按 ID 重建。
- 物品序列化类型和导出字段，恢复为独立 Weapon/Consumable/Key/Item 实例；装备以背包索引绑定，保留物品顺序。职业、技能、贴图和帧资源按项目路径引用。
- 写入先生成 `.tmp` 并检查写入结果，备份上一个有效文件，再替换主文件。读取主文件损坏时尝试 `.bak`；损坏主文件不会覆盖已有有效备份。删除槽位同时删除其临时文件和备份。
- 旧 v1 存档仍可进入所记录章节，但旧版未记录过的等级、耐久、战局位置等信息无法还原；首次使用新版保存后采用 v2。

## 验证与后续边界

完整入口为 `tests/run_tests.ps1`，覆盖 18 组用例，含真实章节 JSON 往返、跨章/跨槽、备份恢复、实际法杖确认与战斗结算。测试存储位于已忽略的 `tests/.runtime_saves/`，不读写玩家槽位；命令见 `tests/README.md`。

本轮没有进行人工完整通关、全部动画逐帧验收和发布包性能测量。保留既有 UI 演出与素材；寻路堆、威胁范围缓存、图集合并、完整行动结果类型及进一步减少共享状态，仍应按测量结果和后续功能逐步实施。
