# 战斗系统架构与规则说明

本项目战斗系统遵循 GBA《火焰纹章》（圣魔之光石）经典规则，采用“数据计算与表现层严格解耦”的设计模式。

---

## 一、核心模块与职责分工

| 模块 / 脚本 | 职责与设计约束 |
| :--- | :--- |
| `scripts/battle_calculator.gd` | **战斗纯计算器（无状态）**：只负责序列生成、攻速、追击、命中率、必杀率、经验公式等纯数据运算，禁止直接修改任何游戏状态。 |
| `scripts/battle_combat.gd` | **战斗结算执行器**：管理战斗循环、实际耐久扣减、掷骰判定、动画播放调用及战后经验结算。 |
| `scene/ui/battle_animation.gd` | **战斗画面表现层**：近景打击演出（物理攻击、魔法三段起手/循环/收手演出、血条扣减、闪白与 MISS 演出）。 |
| `scripts/battle_forecast.gd` | **战斗预览面板**：战前信息展示（双方名字、武器、威力、命中、必杀、追击标识 `x2`）。与实际开战完全共用同一战斗序列数据，禁止私自重算。 |

---

## 二、战斗序列生成流程（Battle Sequence）

每次开战或唤起战斗预览时，由 `BattleCalculator.generate_battle_sequence()` 预生成打击队列：

```text
[发起战斗]
   │
   ├─► 1. 攻方攻击（勇者武器则连续打 2 击）
   │
   ├─► 2. 守方反击判定（守方存活 + 攻击距离在守方武器 min_range..max_range 内）
   │      └─► 若可反击：守方攻击（勇者武器连击 2 次）
   │
   └─► 3. 追击判定（双方攻速差 AS ≥ 4）
          ├─► 攻方追击：攻方再次攻击（勇者武器连打 2 次，共 4 击）
          └─► 守方追击（须满足可反击条件）：守方再次攻击（勇者武器打满 4 击）
```

- **攻速公式 (Attack Speed)**：
  $$AS = 速度 - \max(0, 武器重量 - 体格)$$
- **追击条件**：攻速差 $\Delta AS \ge 4$。
- **射程限制**：防御方反击与追击共享射程判定（如弓箭手在 1 格遭遇近战攻击时，既不反击也不追击）。

## 三、伤害、相克与命中计算公式

### 1. 威力与伤害
- **攻击力 (Atk)**：
  - 物理武器：`力量 + 武器威力 + 相克修正`
  - 魔法武器：`魔力 + 武器威力 + 相克修正`
- **防御力 (Def)**：
  - 守备/魔防（含支援、技能光环加成）+ 地形守备加成
- **单击伤害**：$\max(0, Atk - Def)$（必杀打击伤害 $\times 3$）。

### 2. 三角相克修正 (Weapon Triangle)
- **物理相克**：剑 > 斧 > 枪 > 剑
- **魔法相克**：理 > 光 > 暗 > 理
- **克制效果**：攻击力 $+1$，命中率 $+15\%$；**被克效果**：攻击力 $-1$，命中率 $-15\%$。

### 3. 命中率与回避率
- **有效命中**：`武器命中 + 技巧 × 2 + 幸运 / 2 + 相克修正 + 支援命中加成`
- **防御方回避**：`攻速 × 2 + 幸运 + 地形回避加成 + 支援回避加成`
- **最终命中率**：$\text{clamp}(\text{有效命中} - \text{回避}, 0, 100)$

### 4. 必杀率 (Critical Hit)
- **必杀率**：`武器必杀 + 技巧 / 2 + 支援必杀加成 - 敌方幸运`（封顶 100%，下限 0%）。

## 四、特技与装备属性系统 (Unified Skills)

1. **统一技能数据 (`scripts/skill.gd`)**：
   - 武器、角色个人技能、职业技能统一使用 `Skill` 资源（`.tres`），实现跨载体复用。
2. **光环技能（如【公在】）**：
   - 在计算有效防御/魔防时传入战场单位列表 `all_units`，距离曼哈顿距离 $\le 2$ 格的友军自动享受双防 $+2$。
3. **武器附加特技（如【笃行】）**：
   - S 级武器“断弦”除提供 $+10$ 技、$+10$ 速面板属性外，附带【笃行】特技：攻击后重置行动状态（每回合限 1 次）。
