# Lost (FE8 战棋复刻工程)

本项目使用 **Godot 4.7 Mono (C# / GDScript)** 深度复刻 GBA《火焰纹章》（圣魔之光石）的核心战棋玩法与底层交互体系。项目以长期可维护性为第一准则，严格保持模块解耦与数据计算/表现层分离。

---

## 一、核心特色与系统实现

- **战棋核心系统**：
  - 基于 Dijkstra 的移动范围演算与 A* 寻路。
  - 三角相克（物理 剑>斧>枪>剑；魔法 理>光>暗>理）。
  - 攻速计算与追击判定、武器耐久消耗与战中损坏。
  - 经典近景打击动画与魔法三段演出（起手、特效循环、收尾）。
- **进阶战术系统**：
  - **救援系统（Rescue）**：按 Aid 计算的救出、放下、交接。
  - **再移动（Canto / 焕发）**：行动结束后的剩余移动力二次调度。
  - **交换系统（Trade）**：经典双列背包换装与物品整理。
  - **支援系统（Support）**：按章节出战积累、主动升级对话、3 格内属性贡献制加成。
  - **统一技能与武器特技**：勇者武器连击（普攻 2 击 / 追击 4 击）、S 级神器属性增益与战后重动（笃行）、范围光环（公在）。
- **像素级 UI 复刻**：
  - GBA $240 \times 160$ 像素视口。
  - 人物信息面板（三页循环：角色信息/背包/武器与支援等级）。
  - 运输队面板（仓库取出与背包寄存）。
  - 武器选择菜单与微动属性升降指示箭头（▲ / ▼）。
  - 通用信息查看系统（InfoViewer）：经典“上下避让”排版与手光标跟随。

## 二、运行环境与快捷键操作

### 1. 开发环境
- **引擎版本**：Godot Engine v4.7.stable.mono (64-bit)
- **主场景**：`res://scene/ui/title_screen.tscn`

### 2. 默认键盘键位映射
| 键位 | 映射操作 | 说明 |
| :--- | :--- | :--- |
| **方向键 (↑ ↓ ← →)** | 光标移动 / 菜单选择 | 目标选择时在敌人间循环跳转 |
| **Z** | 确认 (Yes) | 选定单位、确认移动、选定菜单项 |
| **X** | 取消 (No) | 撤回移动、关闭各级菜单与面板 |
| **S / R** | 信息查看 (Info) | 在单位或条目上按下进入 R 键帮助说明 |
| **Shift** | 状态 / 加速 | 加速演出或辅助切换 |
| **Space / Enter** | 开始键 (Start) | 查看全图敌人威胁范围并集 |
